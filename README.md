# Telegram Scanner

Локальное Electron-приложение для поиска публичных Telegram-групп, чтения доступных сообщений, извлечения ссылок и локального поиска.

## Запуск

1. Скопировать `.env.example` в `.env`.
2. Указать `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
3. Выполнить `npm install`.
4. Выполнить `npm start`.

Данные и сессия хранятся в каталоге Electron userData.
